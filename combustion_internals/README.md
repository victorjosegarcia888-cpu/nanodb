# Combustion internals

This module is the boundary for future C++/CUDA combustion and cold-flow solvers.

## Inputs

- Thermodynamic state from `data/parameters/normalized/`.
- Embedded-boundary geometry generated by PicoGK/NanoVDB.
- Cryogenic property tables for LOX and methane.
- Explicit mesh, time-step and chemistry-model metadata.

## Staged implementation

1. Validate units and conservation on a zero-dimensional case.
2. Add a non-reacting pipe and injector cold-flow case.
3. Add a single-phase chamber/nozzle transport case.
4. Add chemistry only after the previous cases converge.
5. Couple the validated state to AMReX EB and GPU diagnostics.

The directory is intentionally a boundary, not a claim that a flight-ready combustion solver exists. A case marked `reference_only` must not be used as an ignition, test or manufacturing specification.
