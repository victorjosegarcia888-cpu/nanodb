1. Especificación conceptual de un “Raptor 3” con tus notas
Vamos a asumir que tu spec oficial está repartida así:

docs/geometry/

RD170.txt, engine2.txt, engines.txt, tablesSutton_motor_plsm.txt, Fundamentals of Rocket Propulsion.pdf  
→ dimensiones de cámara, garganta, expansión, perfiles de tobera, ejemplos de motores de alta presión.

docs/thermodynamics/

thermo.txt, propellant.txt, propellantI.txt, LOX_rp.txt, cap2_termoquimica.pdf  
→ mezcla O/F, presión de cámara, temperatura de combustión, Cp, Cv, densidades, velocidad de sonido.

docs/turbopumps/

cheng.txt, otrsVariabls.txt, other.txt, cohetes.txt, comparativa.txt  
→ RPM, caudal, NPSH, geometría de inducer, curvas de rendimiento.

docs/materials/

Cavity Radiation and Lattice Geometry.pdf, soviet.pdf, NASA TM de prequemadores, UHTC PDFs
→ propiedades UHTC, Inconel, C/C, ablativos, modelos de radiación.

Con eso, el “Raptor 3” conceptual sería:

Propelentes: LOX/LCH₄

Ciclo: FFSC (full-flow staged combustion)

Presión de cámara: alta (ej. 300+ bar, tomada de tablas Sutton + tus notas)

Mezcla O/F: optimizada para Isp y márgenes térmicos (de propellant.txt + propellantI.txt)

Geometría:

cámara corta de alta presión

tobera de expansión alta (vacío) o media (mar)

canales de regeneración en TPMS/gyroid (UHTC engine)

Turbobombas:

LOX y CH₄ con inducer optimizado (de cheng.txt y comparativas)

cavitación controlada vía NPSH y criogenia.

CMakeLists.txt raíz (ejemplo)
cmake
cmake_minimum_required(VERSION 3.24)
project(nanodb_raptor3 LANGUAGES C CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

option(BUILD_PICOGK_VIEWER "Build PicoGK GL viewer" ON)
option(BUILD_CFD_ENGINE    "Build CFD engine (AMReX)" ON)
option(BUILD_UHTC_ENGINE   "Build UHTC engine" ON)

add_subdirectory(picoGK_runtime)
add_subdirectory(geometry_engine)
add_subdirectory(cfd_engine)
add_subdirectory(turbopump_engine)
add_subdirectory(uhtc_engine)
add_subdirectory(manufacturing_engine)
add_subdirectory(visualization)
add_subdirectory(tests)

add_library(geometry_engine
    src/Raptor3ChamberGenerator.cpp
    src/Raptor3NozzleGenerator.cpp
    src/Raptor3ChannelGenerator.cpp
)

target_include_directories(geometry_engine
    PUBLIC include
)

target_link_libraries(geometry_engine

    PUBLIC openvdb
