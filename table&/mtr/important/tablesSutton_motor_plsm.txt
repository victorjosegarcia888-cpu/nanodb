1. CÁLCULO DE FLUJO VOLUMÉTRICO
   Q = ṁ / ρ
   Donde:
     ṁ = Caudal másico (kg/s)
     ρ = Densidad del gas (kg/m³)
   Aplicación: dimensionamiento de líneas criogénicas LOX/CH₄.

2. ÍNDICE DE OXIDACIÓN
   Iox = (O/F) / ((Tad/1000)·4)
   Aplicación: control de mezcla y estabilidad de combustión.

3. DISOCIACIÓN TERMODINÁMICA
   Deq = 0.15 + 0.0001·(T−1500)
   Aplicación: corrección de temperatura efectiva en cámara.

4. PERFIL TÉRMICO OTDF
   OTDF = (Tmax−Tavg)/(Tavg−Tinlet)
   Aplicación: análisis de distorsión térmica en turbina.

5. CONDUCTIVIDAD PLASMÁTICA
   σ = n·e²·τ/m
   Aplicación: ignición por arco eléctrico y estabilidad del chorro.

6. ENERGÍA DE IONIZACIÓN
   Ei = 13.6·(Z²/n²)
   Aplicación: modelado de igniters y descarga de plasma.

7. FLUJO TÉRMICO RADIATIVO
   q'' = ε·σSB·T⁴
   Aplicación: diseño de refrigeración regenerativa.

8. POTENCIA DE TURBINA
   Wt = ṁ·Cp·Tpb·(1−(Pout/Pin)^(γ−1)/γ)·ηt
   Aplicación: prequemadores FFSCC.

9. EFICIENCIA TÉRMICA GLOBAL
   ηth = (0.5·ve²)/LHV
   Aplicación: rendimiento del motor completo.

10. RELACIÓN DE EXPANSIÓN
    Ae/At = (De/Dt)²
    Aplicación: optimización de tobera.

slightly. In the design of tanks and piping systems, an effort is made to minimize the residual propellant.

using System;

namespace RocketComparative
{
    class Program
    {
        static void Main()
        {
            var raptor = new Engine("Raptor", 30e6, 356, 1100);
            var rs25  = new Engine("RS-25", 20e6, 452, 450);

            Compare(raptor, rs25);
        }

        static void Compare(Engine a, Engine b)
        {
            Console.WriteLine($"Comparativa NASA–SpaceX\n");
            Console.WriteLine($"{a.Name} Pc={a.Pc/1e6} MPa Isp={a.Isp} mdot={a.Mdot}");
            Console.WriteLine($"{b.Name} Pc={b.Pc/1e6} MPa Isp={b.Isp} mdot={b.Mdot}");

            double thrustA = a.Mdot * a.Isp * 9.81;
            double thrustB = b.Mdot * b.Isp * 9.81;

            Console.WriteLine($"Thrust A={thrustA/1000} kN");
            Console.WriteLine($"Thrust B={thrustB/1000} kN");
        }
    }

    class Engine
    {
        public string Name;
        public double Pc;
        public double Isp;
        public double Mdot;

        public Engine(string n, double pc, double isp, double md)
        {
            Name = n; Pc = pc; Isp = isp; Mdot = md;
        }
    }
